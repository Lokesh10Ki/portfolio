# Lokesh Devaraj Portfolio

A premium, modern portfolio website for a Data Engineer built with React, TypeScript, TanStack Router, Tailwind CSS, and Framer Motion.

## What this site showcases
- Enterprise data engineering and analytics platform work
- Financial and operational reporting experience
- Databricks, PySpark, SQL, Azure, Power BI, and AI-assisted analytics projects
- A polished, product-like experience suitable for recruiters and hiring teams

## Tech stack
- React
- TypeScript
- TanStack Router
- Tailwind CSS
- Framer Motion
- Vite

## Run locally
```bash
bun install
bun run dev
```

## Build locally
```bash
bun run build
```

## Deployment recommendations
This project is ready to be hosted on:
- Vercel
- Cloudflare Pages
- Netlify

For the best results for your resume, LinkedIn, and Naukri profile, use a clean custom domain such as:
- https://lokesh.dev
- https://www.lokesh.dev

## Suggested deployment steps
1. Push the repository to GitHub.
2. Connect the repo to Vercel or Cloudflare Pages.
3. Deploy the production build.
4. Use the deployed URL in your resume, LinkedIn, and Naukri profile.
