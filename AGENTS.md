# AGENTS.md

Project: Lokesh Devaraj portfolio

Mission
- Build a premium, modern portfolio website for a Data Engineer that feels like a production software product.
- Use the resume, LinkedIn profile, and Naukri profile as the source of truth.
- Keep the existing design language intact while improving clarity, polish, and credibility.

Working rules
- Do not invent experience, achievements, or technologies.
- If information is missing, leave a clear TODO placeholder rather than guessing.
- Prefer reusable components, strict TypeScript, Tailwind CSS, and Framer Motion.
- Improve performance, accessibility, and responsiveness whenever changing UI.
- Explain larger changes before doing major refactors.

Content priorities
- Hero, About, Experience, Projects, Skills, AI Lab, Resume, Contact
- Keep the copy specific to enterprise data engineering, financial analytics, BI, AI-assisted analytics, and platform work.

Deployment guidance
- Push the project to GitHub.
- Recommended hosting: Vercel or Cloudflare Pages.
- Use the deployed URL in the resume, LinkedIn, and Naukri profile.
